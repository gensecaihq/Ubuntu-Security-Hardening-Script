# 1. Introduction

## 1.1 Problem

Today’s cloud GPU setups are often ad-hoc, expensive to operate, and inconsistent for developers. There is no single, coherent, NVIDIA-first AI infrastructure stack on Linux that optimizes developer experience, performance, and cost.

## 1.2 Context

Jensen Huang frames AI infrastructure as an “AI factory” problem, where full-stack co-design of silicon, networking, and software is required to deliver generative and agentic systems at scale.[web:1][web:4][web:5]

## 1.3 Scope

This project designs and documents a Jensen Huang–style cloud GPU AI dev platform built on Rocky Linux, targeting training, inference, and rapid experimentation workflows for AI developers.[web:37][web:38][web:40]
